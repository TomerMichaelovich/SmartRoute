# SmartRoute

Mobile-first, Hebrew/RTL web app that turns a pasted shopping list into an optimized walking route through a supermarket: store map, numbered stops, a route-ordered checklist, and light-touch contextual promotions. Lean MVP for a single demo branch — architecture is built to extend to many chains/branches later without a rewrite.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript (strict) · Tailwind CSS v4 · Zod · Vitest

Data persistence is local JSON files behind repository interfaces (`src/infrastructure/repositories`), so swapping to SQLite/Supabase later touches only that layer — see the plan doc for the full architecture writeup.

## Getting started

```bash
npm install
npm run seed   # writes the demo store/graph/products/promotions into /data
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The customer flow: Home → Branches → paste a shopping list → review classification → route → summary. Admin tools (store/graph/product/promotion CRUD, route preview, analytics) live under `/admin` — no authentication in the MVP.

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Start the dev server (Turbopack) |
| `npm run build` / `npm run start` | Production build / serve |
| `npm run test` / `npm run test:watch` | Vitest unit tests |
| `npm run lint` | ESLint |
| `npm run seed` | Reset `/data` and write the demo dataset |
| `npm run reset-data` | Clear `/data` to empty collections |

## Layout

- `src/domain` — entity types, no framework dependencies
- `src/application` — classification engine, route optimizer, promotion/analytics services
- `src/infrastructure` — JSON repositories, the composition root (`container.ts`), the (stubbed) LLM classifier
- `src/presentation` — UI components, i18n dictionary, hooks, Server Actions
- `app` — Next.js routes (customer flow, `/admin`, API routes)
- `scripts/seed` — the literal demo dataset and the script that writes it to `/data`
- `tests/unit` — Vitest suite for the classification, routing, promotion, and analytics logic

## Notes

- The LLM fallback classification layer is stubbed (no `ANTHROPIC_API_KEY` wired yet) — see `.env.local.example` and `src/infrastructure/llm/anthropic-classifier.ts`.
- `/data` is gitignored; it's regenerated by `npm run seed`.
